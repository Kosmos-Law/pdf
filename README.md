# Kosmic PDF

A lightweight, free and open-source PDF viewer and editor for Linux, built with
Qt (PySide6) and PyMuPDF. OCR and PDF/A use OCRmyPDF, Tesseract and Ghostscript.

## Installing

As a Flatpak, with automatic updates (see `packaging/flatpak/README.md`):

    flatpak install --user https://kosmos.law/flatpak/kosmicpdf.flatpakref

Or from source:

    git clone git@github.com:Kosmos-Law/pdf.git kosmicpdf
    cd kosmicpdf
    ./install.sh

The installer sets up a private Python environment in `.venv` from the pinned
versions in `requirements.txt`, adds Kosmic PDF to the Menu with its icon, and
adds a `kosmicpdf` command. If OCRmyPDF, Tesseract or Ghostscript are missing,
it offers to install them with `apt` (asking first, as that needs your password);
everything except OCR and PDF/A conversion works without them. It installs for
the current user only and is safe to run again, e.g. after `git pull`.

- `./install.sh --default` also makes Kosmic PDF the default app for PDFs.
- `./install.sh --uninstall` removes the Menu entry, icon and command, keeping
  your settings (`~/.config/kosmicpdf`) and the folder.

Needs Python 3.10 or newer with the venv module (`sudo apt install python3-venv`).

## Running

From the Menu (Office), or:

    kosmicpdf [files...]

Only one copy runs at a time: opening another PDF (from the file manager, say)
adds a tab to the running window, so tabs and pages can be dragged between all
windows. Pass `--new-instance` to force a separate process. The icon is
generated by `tools/make_icon.py`.

## Using it

- **Page panel (left):** the button at the left of the toolbar (or F4) shows or
  hides it, and dragging its edge all the way left folds it away; it comes
  back at the width you last gave it.
  Click a thumbnail to jump; Ctrl/Shift-click to select several.
  Drag to reorder. Drag onto another file's thumbnails (or onto its tab) to copy
  pages there; Ctrl-drag within a file duplicates. Right-click for cut, copy,
  paste, delete, rotate, copy to a new PDF, insert blank page, insert from file.
  Ctrl+C / Ctrl+X / Ctrl+V / Delete work on the selected pages. Drop PDFs or
  images from the file manager onto the thumbnails to insert them.
- **Find** (Ctrl+F, or the magnifier beside the zoom buttons): a bar under the
  toolbar searches as you type, starting from the page in view. Enter and
  Shift+Enter (or F3 / Shift+F3) step through the matches. Esc, or the
  magnifier clicked again, closes it; the × in the field clears it. Match Case
  and Whole Words narrow the search. Phrases are found even when they wrap onto
  the next line, and curly and straight apostrophes count as the same.
- **Rotate:** toolbar buttons (or Ctrl+Shift+L / R) rotate all selected pages.
- **Tabs:** drag a tab outside the window to give it its own window; drag it
  onto another window to move it there. Right-click a tab for the same options.
- **Tools** (toolbar or Tools menu, or keys V / H / T / R):
  - *Select*: drag to select text, Ctrl+C to copy, double-click a word. Click
    a note or other annotation to select it, drag to move it, Delete to remove
    it. Highlights stay out of the way: clicks go through to the text.
  - *Highlight*: drag across text (or a box, on scanned pages). With text
    already selected, clicking Highlight (or H) highlights it and stays in
    Select. The arrow beside the button picks the colour, shown as a stripe
    under the highlighter; Clear turns it into an eraser. To recolour or clear
    a highlight, select its text and pick a colour, or Clear.
  - *Typewriter*: click and type; Enter for a new line; click away or Esc to
    finish. Click existing typewriter text to edit it.
  - *Redact* (Tools menu, or R): a tinted bar appears under the toolbar while
    redacting. Drag boxes over content, or use Mark Text to mark every
    occurrence of a word. Nothing is removed until Apply Redactions; saving
    warns if marks are still unapplied. Done goes back to selecting.
- **OCR** (toolbar, next to Save): makes scanned pages searchable. A red dot
  on the button means the document has scanned pages without text, just as a
  red dot on Save means there are unsaved changes.
  `tests/samples/scanned-letter.pdf` is a made-up scan for trying it out
  (regenerate it with `tools/make_scan_sample.py`).
- **Tools menu:** Bates numbering (one file, or every open tab in order,
  continuing the sequence), OCR, Convert to PDF/A, Flatten.
- **File menu:** Combine files into a PDF, Images to PDF (Letter, Legal, A4
  or the image's own size; phone photos are turned upright).

Every edit can be undone (Ctrl+Z) until the file is closed. Saving rewrites the
file completely, so redacted content does not linger in the file.

## Developing

Work on the code in this folder and try it with a development copy that sits
alongside the installed app (e.g. the Flatpak):

    ./install.sh --dev

This adds **Kosmic PDF (Dev)** to the Menu, with a grey icon, and a `kosmicpdf-dev`
command. It runs this folder's code as it stands, so a change is ready to try as
soon as it's saved: just reopen the Dev copy. Its windows are titled
"… — Kosmic PDF (Dev)", it runs as its own process (files opened in it never go to
the installed app, or the other way round), and it is never made the default PDF
app, though it is offered under Open With. Its recent files and settings are in
`~/.config/kosmicpdf`, apart from the Flatpak's. `./install.sh --dev --uninstall`
removes it.

When a version is ready, publish it as a Flatpak release
(`packaging/flatpak/README.md`); the installed app then updates to it.
